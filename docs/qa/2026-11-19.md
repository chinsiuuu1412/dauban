# Nghiệm thu prototype Dấu Bản — 19/11/2026

## Môi trường

- Kiểm thử trên nhánh `main` local tại `D:\dauban\dauban`. Next.js 16.4.6, Node.js 26.13.1 và npm 11.20.0.
- Các ca trình duyệt chạy trên **`frontend/out/`**, phục vụ bằng HTTP tĩnh tại loopback và gắn dưới `/dauban`. Bản build dùng `NEXT_PUBLIC_BASE_PATH=/dauban` và URL QR thử nghiệm `https://example.com/dauban/`. Trình duyệt là Chrome qua Playwright, desktop 1440 × 900 và mobile mô phỏng 360 × 780.
- Dev server tại `http://127.0.0.1:3000/trang-chu/` trả HTTP 200. Bằng chứng nghiệm thu dưới đây đến từ bản export. Bản `out/` sau bàn giao đã được build lại cho cấu hình local mặc định, với base path rỗng và QR công khai ở trạng thái chờ.
- Chạy `npm.cmd run lint`, `npm.cmd run typecheck`, `npm.cmd test` và `npm.cmd run build` từ `frontend/`. Repo có đủ bốn script. Các log và ảnh chụp liên kết bên dưới nằm trong thư mục bằng chứng local, được Git bỏ qua.

Không phát hiện lỗi sản phẩm trong các ca local đã chạy. Các ca camera thật và URL Pages còn chờ theo phạm vi bàn giao local. Bước này chỉ thêm báo cáo, không cần sửa mã ứng dụng hoặc tạo quiz. Ba tài liệu nghiệp vụ được đối chiếu SHA-256 với mốc trước đó.
